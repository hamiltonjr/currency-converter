# Currency Converter

A simple console-based currency converter built with Java.

## About the Project

This project converts an amount from US dollars (USD) to Brazilian reais (BRL) using an exchange rate provided by the user in the code.

It is the first stage of a project that will evolve into a web application.

## Technologies

- Java 17
- Maven

## Current Features

- Converts USD to BRL.
- Displays the exchange rate and converted amount.
- Formats monetary values to two decimal places.

## How to Run

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Run the `Main` class.
